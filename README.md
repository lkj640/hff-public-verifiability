# Public verifiability of regulatory evidence: Korean health functional food ingredients

Reproducibility package for:

> Lee, C. *How Much of the Evidence Behind Regulatory Approval Is Publicly Verifiable? A Meta-Research Census of 611 Functional Ingredients in Korean Health Functional Foods.* Submitted to *Accountability in Research*.

This repository contains the de-identified dataset, the scoring codebook, and the code that reproduces every statistic, Table 2, Table 3 and Figures 1–3 of the manuscript.

## Contents

| Path | Description |
|---|---|
| `data/ingredients.csv` | One row per recognition record (N = 611): pathway, functional category, recognition year, whether public human-trial literature was found, seven domain grades (1–5), composite score, number of retained articles, funding category. |
| `data/retained_records_notified.csv` | Retained publications (PMID, journal, year, title, URL) for notified ingredients. |
| `codebook/codebook.md` | Grade anchors for all seven domains, weights, and the decision rules used for the binary criteria. |
| `analysis/reproduce.py` | Reproduces all results from `data/ingredients.csv`. |
| `results/` | Output of `reproduce.py`: `results.md` (all reported numbers), `table2.csv`, `table3.csv`, `categories.csv`. |
| `figures/` | Figures 1–3 as generated by `reproduce.py`. |
| `tools/extract_from_website.py` | Builds `data/` from the HTML snapshot of the author's evidence website (not included). |

## Reproducing the results

Requires Python ≥ 3.10.

```bash
pip install -r requirements.txt
python analysis/reproduce.py
```

The script checks that every composite score equals Σ (grade / 5 × weight) before computing anything, then writes `results/` and `figures/`.

## Dataset

**Snapshot.** Assessments were finalized between 11 and 15 September 2026 (`verified_date`). The manuscript uses this snapshot only. The public website may be updated later; those updates do not change this dataset.

**Unit of analysis.** A recognition record of the Korean Ministry of Food and Drug Safety (MFDS). Some materials hold more than one recognition, for example for different applicants, and each recognition is a separate row.

**Pathways.** `notified`: ingredients listed in the Health Functional Food Code (n = 85; identified by code and English name). `individually_recognized`: ingredients recognized on the basis of an applicant's dossier (n = 526; pseudonymous IDs `IR-001` … `IR-526`). Fourteen individually recognized records carry Code-style numbers without the notified label (`code_style_number_without_notified_label = 1`). They are kept in the individually recognized pathway, as on the website.

**Key variables**

| Variable | Meaning |
|---|---|
| `scored` | 1 if at least one publicly retrievable human study or systematic review matching the ingredient and its recognized function was retained; 0 otherwise |
| `grade_design`, `grade_sample`, `grade_journal`, `grade_repro`, `grade_effect`, `grade_coi`, `grade_safety` | Domain grades, 1–5 (see `codebook/codebook.md`) |
| `composite_score` | Σ (grade / 5 × weight), maximum 100 |
| `funding_category` | `manufacturer_sponsored_or_led` (funding grade 1–2), `not_reported` (3), `independent_documented` (4–5) |
| `n_retained_articles` | Number of retained publications |
| `recognition_year` | Year from year-coded recognition numbers (blank when not available) |

`not_reported` means that no funding statement could be found in the retained publications. It is **not** evidence of industry funding or of a conflict of interest.

## Interpretation

The composite index is an investigator-developed **descriptive** index. It summarizes how much human-trial evidence is publicly retrievable for each ingredient and what that evidence looks like. It has not been psychometrically validated. It is **not** a measure of an ingredient's efficacy, of product quality, or of the adequacy of the confidential dossiers reviewed by the regulator. A low score means that little matching evidence could be found in the public record. It does not mean that the recognized function is false.

## Limitations relevant to reuse

- All inclusion decisions and grades were made by a single assessor; inter-rater reliability has not been estimated.
- A large language model (Claude, Anthropic) assisted literature searching and first-pass extraction. All values were checked against the full texts by the author.
- Per-ingredient search dates, exact search strings and lists of excluded records were not logged, so the searches cannot be re-run exactly.

Corrections and additional human-trial evidence are welcome via an issue in this repository.
